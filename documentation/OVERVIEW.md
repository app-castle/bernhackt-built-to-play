# Project Overview: Multiplayer Desktop Pet Game

A multiplayer desktop pet game where pets live on your desktop (Bongo Cat style) and can interact with other players' pets.

### Key Features:

- **Pet Training**: Train your pet via keystrokes.
- **Pet-Sitting**: Send pets to other players to earn EXP.
- **Card Combat**: Turn-based 1v1 battles using equipment and action cards.
- **Quests & Events**: Progress through quests and experience random in-game events.
- **Multiplayer**: Real-time interaction and organized tournaments.
